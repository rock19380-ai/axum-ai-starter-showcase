# Security and Public Scope

This repository is a curated engineering showcase for **Axum AI Starter**.

It is **not** a mirror of the private production/commercial source repository. The private repository remains the implementation authority and may contain additional code, migrations, evidence, operations material, and active-development work that is intentionally not published here.

Public examples in this repository are simplified, independently written demonstrations of engineering concepts. They must not be treated as production payment, authorization, custody, or security code.

No private keys, API secrets, signed payment credentials, production database URLs, internal evidence bundles, or private Git history should be committed here.
